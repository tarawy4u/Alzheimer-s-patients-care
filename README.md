تطبيق ذكي ومطور خصيصاً بمحبة واهتمام (تطبيق محمد لرعاية والدته الغالية)، يهدف إلى مساعدة مقدمي الرعاية في إدارة الحياة اليومية لمرضى ألزهايمر وكبار السن، وتوفير بيئة آمنة، منظمة، ومليئة بالدفء الإنساني.

---

## ✨ المميزات الرئيسية (Key Features)

* **⏰ تذكيرات الأدوية الذكية:** تنبيهات دقيقة ومنتظمة (مثل أدوية الضغط والسكر في تمام الساعة 9:00 صباحاً) مع تنبيهات صوتية واضحة وموثوقة.
* **🎙️ رسائل الاطمئنان الصوتية:** إمكانية تسسيل وتشغيل رسائل صوتية بصوت الأبناء أو الأقارب لتقليل شعور المريض بالقلق والتوتر وتعزيز شعوره بالأمان.
* **🎵 موسيقى السكينة والتهدئة:** قوائم تشغيل مخصصة للموسيقى الهادئة للمساعدة في الاسترخاء وتحسين الحالة المزاجية للمريض.
* **🤖 المساعد الذكي (Gemini AI):** مدعوم بنماذج الذكاء الاصطناعي لتقديم دعم وميزات تفاعلية ذكية.
* **👨‍⚕️ إشعار المشرف الطبي:** نظام تنبيهات مخصص للتواصل والمتابعة مع الأطباء والمشرفين الصحيين عند الحاجة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **اللغة:** Kotlin
* **الواجهات:** Jetpack Compose (Modern UI)
* **الذكاء الاصطناعي:** Google Gemini AI API
* **البناء والإدارة:** Gradle KTS, KSP, AndroidX
